# 🎙️ বাংলা ভয়েস AI — Streamlit Cloud সংস্করণ

**The Ultimate Bengali AI Voice Studio** — সম্পূর্ণ ফ্রি, সেলফ-হোস্টেড বাংলা
ভয়েস জেনারেশন প্ল্যাটফর্মের Streamlit সংস্করণ। মোবাইল থেকে ব্যবহারের জন্য
[Streamlit Community Cloud](https://streamlit.io/cloud)-এ ফ্রিতে হোস্ট করা যায়।

## এটা কী করে

- বাংলা স্ক্রিপ্ট লিখলে আসল নিউরাল ভয়েসে (Indic Tiny TTS) অডিও তৈরি করে
- ২টি আসল কণ্ঠ: **নারী** ও **পুরুষ**
- ২৮টি আবেগ ট্যাগ (`[happy]`, `[sad]`, `[deep, mysterious]`…) পার্স করে
- ডকুমেন্টারি মোডের ১০টি প্রিসেট (গতি + বিরতি)
- লম্বা স্ক্রিপ্ট স্বয়ংক্রিয়ভাবে চাঙ্কে ভাগ করে, একসাথে জোড়া দেয়
- অডিও শোনা যায়, **WAV ও MP3 ডাউনলোড** করা যায়
- রাহাত — ন্যারেটরের নমুনা অডিও শোনা যায়

## সত্য কথা (সীমা)

- **TinyTTS একটি শান্ত পাঠ-কণ্ঠ** — এতে আসল আবেগ নিয়ন্ত্রণ নেই। ট্যাগগুলো
  পার্স করা হয়, মুছে ফেলা হয় না, তবে অডিওতে আবেগের পরিবর্তন আসবে না;
  শুধু গতি ও বিরতিতে সামান্য পরিবর্তন হবে। আসল আবেগযুক্ত কণ্ঠের জন্য
  Indic Parler-TTS লাগে, যা GPU ছাড়া চলে না।
- **Indic Parler-TTS-এর ৬টি কণ্ঠ** (অর্জুন, অদিতি, তপন, রশ্মি, অর্ণব,
  রিয়া) ও **IndicF5 ভয়েস ক্লোনিং** এই ফ্রি হোস্টে বন্ধ — GPU প্রয়োজন।
- **রাহাত — ন্যারেটর** শুধু নমুনা হিসেবে আছে; এই কণ্ঠে ভয়েস তৈরি করা
  যায় না (ক্লোনিং করা হয়নি)।
- **ইতিহাস সংরক্ষণ হয় না** — জেনারেশনের ইতিহাস শুধু সেশনে থাকে; পেজ
  রিফ্রেশ করলে মুছে যায়। অডিও ডাউনলোড করে রাখুন।
- Streamlit Cloud-এর ফ্রি অ্যাপ **নিষ্ক্রিয় থাকলে ঘুমিয়ে যায়** — প্রথম
  খোলায় ~৩০–৬০ সেকেন্ড লাগতে পারে। প্রথম Generate-এ মডেল (~৯০ MB)
  ডাউনলোড হয়, ~১ মিনিট লাগে।

## লোকালি চালানো

```bash
# Python 3.12 প্রয়োজন
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run streamlit_app.py
```

তারপর ব্রাউজারে http://localhost:8501 খুলুন।

## Streamlit Cloud-এ ডিপ্লয় (ফ্রি)

1. এই ফোল্ডারের সব ফাইল একটি **পাবলিক GitHub রিপো**-তে পুশ করুন
   (রুটে `streamlit_app.py` থাকতে হবে)।
2. https://share.streamlit.io-তে গিয়ে **New app** → রিপো, ব্রাঞ্চ,
   `streamlit_app.py` বেছে নিন → **Deploy**।
3. কোনো ক্রেডিট কার্ড লাগে না। অ্যাপের লিংক পাবেন —
   `https://<app>.streamlit.app` — মোবাইল ব্রাউজার থেকেও চলবে।

## ফাইল গঠন

```
streamlit_app.py          # অ্যাপের মূল ফাইল (এন্ট্রি পয়েন্ট)
requirements.txt          # torch CPU + streamlit + lameenc (পিন করা ভার্সন)
app/
  textnorm.py             # বাংলা টেক্সট নরমালাইজেশন (FastAPI অ্যাপ থেকে নেওয়া)
  emotion.py              # ২৮ ট্যাগ পার্সার + অটো শনাক্তকরণ (নেওয়া)
  chunker.py              # স্ক্রিপ্ট চাঙ্কিং (নেওয়া)
  audio_lite.py           # numpy/wave মার্জ + QC + lameenc MP3 (ffmpeg নেই)
  presets.py              # ডকুমেন্টারি মোডের ১০ প্রিসেট
  config.py               # ছোট সেটিংস (ডাটাবেস নেই)
  engines/
    base.py               # ইঞ্জিন ইন্টারফেস (নেওয়া)
    tiny.py               # Indic Tiny TTS লোডার (নেওয়া, lazy-load)
voices/
  rahat_narrator_sample.mp3   # রাহাতের নমুনা (৩ মি ১৭ সে)
tests/
  test_streamlit_core.py  # এন্ড-টু-এন্ড টেস্ট (মডেল + WAV + MP3)
```

## টেস্ট

```bash
.venv/bin/python tests/test_streamlit_core.py
```

আসল বাংলা প্যারাগ্রাফ দিয়ে মডেল লোড, সিন্থেসিস, মার্জ, QC, WAV ও MP3
যাচাই করে।
