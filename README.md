# 🎙️ BanglaVoice Studio — Streamlit Cloud সংস্করণ (v4)

**প্রাকৃতিক বাংলাদেশি বাংলা ন্যারেশন — সম্পূর্ণ ফ্রি।** প্রাথমিক ইঞ্জিন
**Microsoft Edge TTS** (বাংলাদেশি কণ্ঠ প্রদীপ), ফলব্যাক **Indic Tiny TTS**।
কোনো পেইড API নেই, কোনো API key লাগে না, কোনো Google Cloud নেই।

লাইভ: **https://bangla-voice-ai.streamlit.app**

## v4-এ যা নতুন (Edge TTS ইন্টিগ্রেশন)

- **প্রাথমিক ইঞ্জিন Microsoft Edge TTS** — `edge-tts==7.3.1` (Streamlit
  Cloud-এ পরীক্ষিত সংস্করণ)। ৪টি আসল বাংলা নিউরাল কণ্ঠ:
  - **প্রদীপ** (bn-BD, পুরুষ) — প্রাথমিক কণ্ঠ, ডকুমেন্টারি ন্যারেশন
  - **নবনীতা** (bn-BD, নারী)
  - **ভাস্কর** (bn-IN, পুরুষ)
  - **তানিশা** (bn-IN, নারী)
- **১১টি ডকুমেন্টারি ট্যাগ → আসল SSML** — প্রতিটি বাক্যের ট্যাগ
  `<prosody rate/pitch>` ও `<break>`-এ অনুবাদ হয়, বাক্যের সীমানায়
  প্রয়োগ হয়, ট্যাগ পড়া হয় না:

  | ট্যাগ | SSML অনুবাদ |
  |---|---|
  | [Deep] | গতি −10%, পিচ −8% |
  | [Mysterious] | গতি −10%, পিচ −5% |
  | [Serious] | গতি −5%, পিচ −3% |
  | [Emotional] | পিচ +5% |
  | [Whisper] | গতি −5%, পিচ −3% (আনুমানিক — আসল ফিসফিস নয়) |
  | [Excited] | গতি +12%, পিচ +6% |
  | [Surprised] | গতি +8%, পিচ +8% |
  | [Calm] | গতি −8% |
  | [Powerful] | গতি −5%, পিচ −5% |
  | [Pause] | বিরতি ১.০ সেকেন্ড |
  | [Long Pause] | বিরতি ২.৫ সেকেন্ড |

  একাধিক ট্যাগ থাকলে গতি/পিচ গড় করা হয়, বিরতি সবচেয়ে বড়টা নেওয়া
  হয়। পুরনো ২৮টি ট্যাগও চলে — সেগুলো সবচেয়ে কাছের আনুমানিক রূপে
  অনুবাদ হয়। **আসল আবেগ নিয়ন্ত্রণ Edge TTS-এ নেই** — এটা UI ও সাহায্য
  ট্যাবে স্পষ্ট লেখা আছে।
- **ভয়েস সেটিংস (আসল নিয়ন্ত্রণ, SSML-এ ম্যাপ করা):** গতি ৫ ধাপ
  (ধীর −25% / একটু ধীর −12% / স্বাভাবিক / একটু দ্রুত +12% / দ্রুত
  +25%), পিচ ৩ ধাপ (নিচু −10% / স্বাভাবিক / উঁচু +10%), বাক্যের বিরতি,
  অনুচ্ছেদের বিরতি, ভয়েস গেইন। সেটিংস সেশনে থাকে।
- **ব্যর্থ চাঙ্কের পুনঃচেষ্টা:** কোনো চাঙ্ক নেটওয়ার্ক সমস্যায় ব্যর্থ
  হলে শুধু সেই চাঙ্ক আবার তৈরি হয় — পুরো স্ক্রিপ্ট নয়, সফল চাঙ্কগুলো
  আবার তৈরি হয় না। ব্যর্থ চাঙ্কের অডিও বাদ দিয়ে বাকিটা মার্জ হয়।
- **নতুন ট্যাব সাজানো (৮টি):** 📊 ড্যাশবোর্ড, 🎙️ ভয়েস স্টুডিও,
  🎤 ভয়েস লাইব্রেরি, 🎧 কাস্টম ভয়েস, 📁 আমার প্রজেক্ট,
  🎵 মিউজিক স্টুডিও, ⚙️ অ্যাডমিন, ❓ সাহায্য।
- **সব ত্রুটি বাংলায়** — কাঁচা traceback ব্যবহারকারীকে দেখানো হয় না;
  কারিগরি বিবরণ শুধু সার্ভার লগে যায়। কণ্ঠ ব্যর্থ হলে অন্য বাংলা কণ্ঠ
  বেছে নেওয়ার সুযোগ দেওয়া হয় — **কখনো নীরবে অন্য ভাষা বা Tiny-তে
  ফলব্যাক হয় না** (Tiny শুধু ব্যবহারকারীর পছন্দে)।
- **প্রজেক্টে ইঞ্জিন সংরক্ষণ:** প্রজেক্ট এখন ইঞ্জিন (Edge/Tiny),
  গতি ও পিচসহ সংরক্ষিত হয়; খুললে ও আবার তৈরি করলে একই সেটিংস ফিরে আসে।

## v3-এর ফিচার (অপরিবর্তিত)

- **মিউজিক স্টুডিও:** নিজের MP3 আপলোড বা সিনথেসাইজ করা আবহ সঙ্গীত,
  ভয়েস+মিউজিক মিক্স, ভলিউম/ব্যালান্স, ফেইড ইন/আউট, ডাকিং,
  ভয়েস-শুধু ও ভয়েস+মিউজিক এক্সপোর্ট।
- **ভয়েস প্রোফাইল:** ডকুমেন্টারি প্রিসেট + সংরক্ষণযোগ্য প্রোফাইল।
- **ব্রাউজার প্রিভিউ:** ডিভাইসের নিজের বাংলা ভয়েসে দ্রুত শোনা —
  প্রিভিউ মাত্র, আসল কণ্ঠ নয়।
- **অ্যাডমিন:** ইঞ্জিনের অবস্থা, CPU/RAM, মডেলের তথ্য, কণ্ঠ চালু/বন্ধ।

## v2-এর ফিচার (অপরিবর্তিত)

- **স্টুডিও:** বাংলা স্ক্রিপ্ট, অক্ষর/শব্দ/বাক্য গণনা, আনুমানিক সময়,
  ২৮টি আবেগ ট্যাগ পার্স, ডকুমেন্টারি মোডের ১০টি প্রিসেট, লম্বা স্ক্রিপ্ট
  স্বয়ংক্রিয় চাঙ্কিং + মার্জ, ওয়েভফর্ম, সেগমেন্ট প্লেয়ার, WAV/MP3
  ডাউনলোড, QC নোট।
- **ভয়েস লাইব্রেরি:** Tiny নারী/পুরুষ (ফলব্যাক), রাহাত — ন্যারেটর
  (নমুনা মাত্র, তৈরি করা যায় না), Parler-এর ৬ কণ্ঠ ও IndicF5 ক্লোনিং
  **অনুপলব্ধ** (GPU প্রয়োজন) — নকল করা হয় না।
- **কাস্টম ভয়েস স্টুডিও:** নমুনা আপলোড + যাচাই + প্রোফাইল (সেশন-মাত্র)।
  **কোনো ক্লোনিং হয় না।**
- **আমার প্রজেক্ট:** JSON ফাইলে সংরক্ষণ; ডাউনলোড করা .json-ই স্থায়ী কপি।

## সীমা (সত্য কথা — সাহায্য ট্যাবেও লেখা আছে)

- **Edge TTS একটি নেটওয়ার্ক সার্ভিস** — ইন্টারনেট ছাড়া কাজ করবে না।
  Microsoft-এর সার্ভিস সাময়িকভাবে বন্ধ থাকলে বাংলা ত্রুটি দেখাবে;
  তখন Tiny ফলব্যাক ব্যবহার করুন। Microsoft সার্ভিস বদলালে বা সীমিত
  করলে অ্যাপ সেটা জানাবে — Tiny সবসময় বিকল্প হিসেবে আছে।
- **আসল আবেগ নিয়ন্ত্রণ নেই** — ট্যাগ শুধু গতি, পিচ ও বিরতি বদলায়।
  [Whisper] আসল ফিসফিস নয়।
- **Tiny ইঞ্জিন শান্ত পাঠ-কণ্ঠ** — আবেগ নিয়ন্ত্রণ নেই, লাতিন শব্দ
  বাদ দেয়।
- **প্রজেক্ট স্থায়ী নয়** — অ্যাপ ঘুমিয়ে গেলে সার্ভারের ফাইল মুছে
  যায়; .json ডাউনলোডই স্থায়ী কপি।
- **প্রথম Generate ধীর** — Tiny ইঞ্জিনে প্রথমবার মডেল ডাউনলোড
  (~৯০ MB) হতে ~১ মিনিট লাগতে পারে।
- **অ্যাপ ঘুমিয়ে যায়** — নিষ্ক্রিয় থাকলে Streamlit Cloud অ্যাপটি
  ঘুম পাড়ায়; আবার খুলতে ~৩০–৬০ সেকেন্ড লাগতে পারে।
- **GPU ইঞ্জিন নেই** — Parler-TTS (৬ কণ্ঠ, আসল আবেগ) ও IndicF5
  ক্লোনিং GPU ছাড়া এই ফ্রি হোস্টে চলে না।

## কীভাবে চালাবেন (Streamlit Community Cloud — ফ্রি)

1. GitHub-এ পাবলিক রিপো তৈরি করুন, এই ফোল্ডারের সব ফাইল আপলোড করুন
   (`streamlit_app.py`, `requirements.txt`, `app/`, `voices/`,
   `.streamlit/config.toml`)।
2. https://share.streamlit.io → "Create app" → রিপো, ব্রাঞ্চ `main`,
   মেইন ফাইল `streamlit_app.py` → Deploy।
3. প্রথম Generate-এ মডেল ডাউনলোড হতে ~১ মিনিট লাগতে পারে।
4. URL হবে `https://<app>.streamlit.app` — ফোনের ব্রাউজার থেকে খুলুন।

## লোকালভাবে চালানো

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run streamlit_app.py
```

তারপর http://localhost:8501 খুলুন।

**দ্রষ্টব্য:** এই VM-এ Edge TTS সংশ্লেষণ চলে না (egress প্রক্সি
WebSocket handshake ভেঙে দেয়) — তাই লোকালে Edge কণ্ঠে Generate
করলে নেটওয়ার্ক ত্রুটি দেখাবে। Streamlit Cloud-এ Edge কাজ করে
(২০২৬-১১-২৬-এ টেস্ট অ্যাপে প্রমাণিত: bn-BD-PradeepNeural দিয়ে আসল
৩ সেকেন্ডের MP3 তৈরি হয়েছিল)। লোকালে Tiny ইঞ্জিন পুরোপুরি চলে।
