# 🎙️ বাংলা ভয়েস AI — Streamlit Cloud সংস্করণ

**The Ultimate Bengali AI Voice Studio** — সম্পূর্ণ ফ্রি, সেলফ-হোস্টেড বাংলা
ভয়েস জেনারেশন প্ল্যাটফর্মের Streamlit সংস্করণ। মোবাইল থেকে ব্যবহারের জন্য
[Streamlit Community Cloud](https://streamlit.io/cloud)-এ ফ্রিতে হোস্ট করা যায়।

লাইভ: **https://bangla-voice-ai.streamlit.app**

## v2-এ যা আছে

৫টি ট্যাব (একটিই এন্ট্রি পয়েন্ট — `streamlit_app.py`):

1. **🎙️ স্টুডিও** (v1-এর স্টুডিও অপরিবর্তিত)
   - বাংলা স্ক্রিপ্ট লিখলে আসল নিউরাল ভয়েসে (Indic Tiny TTS) অডিও তৈরি
   - ২টি আসল কণ্ঠ: **নারী** ও **পুরুষ**
   - ২৮টি আবেগ ট্যাগ (`[happy]`, `[sad]`, `[deep, mysterious]`…) পার্স
   - ডকুমেন্টারি মোডের ১০টি প্রিসেট (গতি + বিরতি)
   - লম্বা স্ক্রিপ্ট স্বয়ংক্রিয়ভাবে চাঙ্কে ভাগ, একসাথে জোড়া
   - **ভয়েস সেটিংস:** গতি, বাক্যের মাঝে বিরতি, চাঙ্কের মাঝে বিরতি
     (প্রতিটি বাক্য আলাদাভাবে তৈরি হয় বলে বাক্যের বিরতিটা আসল),
     ডিফল্টে ফেরানোর বোতাম। পিচ/স্থিতিশীলতা/সাদৃশ্য TinyTTS সমর্থন
     করে না — তাই দেখানো হয় না।
   - **স্বয়ংক্রিয় আবেগ:** প্রতিটি বাক্যের প্রস্তাবিত আবেগ দেখা যায় ও
     বদলানো যায়; স্ক্রিপ্টের ম্যানুয়াল `[ট্যাগ]` সবসময় জিতবে।
   - **নরমালাইজেশন প্রিভিউ:** ইঞ্জিন আসলে যা পড়বে (যেমন ডা. → ডাক্তার,
     1945 → ১৯৪৫) — মূল স্ক্রিপ্ট আলাদা রাখা হয়।
   - **অডিও স্টুডিও:** সম্পূর্ণ অডিওর ওয়েভফর্ম ছবি (PIL দিয়ে আঁকা),
     সম্পূর্ণ প্লেব্যাক, প্রতিটি সেগমেন্টের আলাদা প্লেয়ার + WAV/MP3
     ডাউনলোড, সেগমেন্ট তালিকা, QC নোট
   - অডিও শোনা যায়, **WAV ও MP3 ডাউনলোড** করা যায়
2. **🎤 ভয়েস লাইব্রেরি** — প্রতিটি কণ্ঠের কার্ড: নাম, বিবরণ, স্টাইল,
   নমুনা শোনার বোতাম। আসল কণ্ঠ (নারী/পুরুষ) + রাহাতের নমুনা।
   Parler-এর ৬টি কণ্ঠ ও IndicF5 ক্লোনিং **অনুপলব্ধ** বলে দেওয়া আছে
   (GPU প্রয়োজন) — নকল করা হয় না।
3. **🎧 কাস্টম ভয়েস স্টুডিও** — WAV/MP3 নমুনা আপলোড, ধরন + সময়কাল +
   RMS/নীরবতা যাচাই, প্রিভিউ, নাম দিয়ে প্রোফাইল সংরক্ষণ (এই সেশন),
   মুছে ফেলা, প্রোফাইল তথ্যের JSON ডাউনলোড। **কোনো ক্লোনিং হয় না** —
   প্রোফাইল শুধু নমুনা হিসেবে থাকে; আসল ক্লোনিংয়ে IndicF5 + GPU লাগে।
4. **📁 আমার প্রজেক্ট** — নাম দিয়ে প্রজেক্ট সংরক্ষণ (স্ক্রিপ্ট + কণ্ঠ +
   প্রিসেট + সেটিংস) `data/projects/*.json` ফাইলে; খুলুন / আবার তৈরি
   করুন / নাম বদলান / মুছুন / অডিও ডাউনলোড। প্রজেক্ট ফাইল (.json)
   **ডাউনলোড ও আপলোড** করা যায় — সেটাই স্থায়ী কপি।
5. **⚙️ অ্যাডমিন** — ইঞ্জিনের অবস্থা (Tiny ✅, Parler/IndicF5 ❌ +
   কারণ), লাইভ CPU/RAM (psutil), মডেলের তথ্য, এই সেশনের পরিসংখ্যান
   (জেনারেশন, মোট অডিও, চাঙ্ক, ব্যর্থ), কণ্ঠ চালু/বন্ধ (শুধু এই সেশন),
   ডিস্কে প্রজেক্টের আকার। কোনো ব্যবহারকারী অ্যাকাউন্ট নেই।

## সত্য কথা (সীমা)

- **TinyTTS একটি শান্ত পাঠ-কণ্ঠ** — এতে আসল আবেগ নিয়ন্ত্রণ নেই। ট্যাগগুলো
  পার্স করা হয়, মুছে ফেলা হয় না, তবে অডিওতে আবেগের পরিবর্তন আসবে না;
  শুধু গতি ও বিরতিতে সামান্য পরিবর্তন হবে। আসল আবেগযুক্ত কণ্ঠের জন্য
  Indic Parler-TTS লাগে, যা GPU ছাড়া চলে না।
- **Indic Parler-TTS-এর ৬টি কণ্ঠ** (অর্জুন, অদিতি, তপন, রশ্মি, অর্ণব,
  রিয়া) ও **IndicF5 ভয়েস ক্লোনিং** এই ফ্রি হোস্টে বন্ধ — GPU প্রয়োজন।
- **রাহাত — ন্যারেটর** ও কাস্টম প্রোফাইল শুধু নমুনা হিসেবে আছে; এই কণ্ঠে
  ভয়েস তৈরি করা যায় না (ক্লোনিং করা হয়নি)।
- **প্রজেক্ট স্থায়ী নয়** — সার্ভারে সংরক্ষিত প্রজেক্ট অ্যাপ ঘুমিয়ে গেলে
  বা রিস্টার্ট হলে মুছে যায়। `.json` ডাউনলোডই স্থায়ী কপি। কাস্টম
  ভয়েস প্রোফাইল ও ইতিহাস শুধু সেশনে থাকে; পেজ রিফ্রেশ করলে মুছে যায়।
- **দীর্ঘ অডিওতে সেগমেন্ট MP3 বাদ** — মোট অডিও ১০ মিনিটের বেশি হলে বা
  চাঙ্ক ৪০টির বেশি হলে RAM বাঁচাতে সেগমেন্ট MP3 তৈরি হয় না (সেগমেন্ট
  WAV ও সম্পূর্ণ MP3 থাকে)।
- **MP3 নমুনার সময়কাল মাপা যায় না** — এই অ্যাপে MP3 ডিকোডার নেই, তাই
  কাস্টম ভয়েসে MP3-এর সময়কাল “জানা যায়নি” দেখায় (তবুও রাখা যায়)।
- Streamlit Cloud-এর ফ্রি অ্যাপ **নিষ্ক্রিয় থাকলে ঘুমিয়ে যায়** — প্রথম
  খোলায় ~৩০–৬০ সেকেন্ড লাগতে পারে। প্রথম Generate-এ মডেল (~৯০ MB)
  ডাউনলোড হয়, ~১ মিনিট লাগে।
- RAM: সর্বোচ্চ পরিমাপ **৪২৩.৫ MB** (১ GB সীমার অনেক নিচে)।

## লোকালি চালানো

```bash
# Python 3.12 প্রয়োজন
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run streamlit_app.py
```

তারপর ব্রাউজারে http://localhost:8501 খুলুন।

## Streamlit Cloud-এ ডিপ্লয় (ফ্রি)

1. এই ফোল্ডারের সব ফাইল একটি **পাবলিক GitHub রিপো**-তে পুশ করুন
   (রুটে `streamlit_app.py` থাকতে হবে)।
2. https://share.streamlit.io-তে গিয়ে **New app** → রিপো, ব্রাঞ্চ,
   `streamlit_app.py` বেছে নিন → **Deploy**।
3. কোনো ক্রেডিট কার্ড লাগে না। অ্যাপের লিংক পাবেন —
   `https://<app>.streamlit.app` — মোবাইল ব্রাউজার থেকেও চলবে।

## ফাইল গঠন

```
streamlit_app.py          # অ্যাপের মূল ফাইল (এন্ট্রি পয়েন্ট, ৫ ট্যাব)
requirements.txt          # torch CPU + streamlit + lameenc + psutil (পিন করা)
app/
  textnorm.py             # বাংলা টেক্সট নরমালাইজেশন (FastAPI অ্যাপ থেকে নেওয়া)
  emotion.py              # ২৮ ট্যাগ পার্সার + অটো শনাক্তকরণ (নেওয়া)
  chunker.py              # স্ক্রিপ্ট চাঙ্কিং (নেওয়া)
  audio_lite.py           # numpy/wave মার্জ + QC + lameenc MP3 + ওয়েভফর্ম (ffmpeg নেই)
  generate.py             # জেনারেশন কোর — প্রতি-বাক্য সিন্থেসিস, সেগমেন্ট, ওয়েভফর্ম
  presets.py              # ডকুমেন্টারি মোডের ১০ প্রিসেট
  config.py               # ছোট সেটিংস (ডাটাবেস নেই)
  projects.py             # প্রজেক্ট JSON ফাইল (data/projects/) — v2
  custom_voices.py        # নমুনা যাচাই + প্রোফাইল (ক্লোনিং নেই) — v2
  engines/
    base.py               # ইঞ্জিন ইন্টারফেস (নেওয়া)
    tiny.py               # Indic Tiny TTS লোডার (নেওয়া, lazy-load)
voices/
  rahat_narrator_sample.mp3   # রাহাতের নমুনা (৩ মি ১৭ সে)
  sample_female.wav           # নারী কণ্ঠের নমুনা (৫.৩ সে, আসল Tiny আউটপুট)
  sample_male.wav             # পুরুষ কণ্ঠের নমুনা (৫.৭ সে, আসল Tiny আউটপুট)
tests/
  test_streamlit_core.py  # এন্ড-টু-এন্ড টেস্ট (মডেল + WAV + MP3)
  test_app_ui.py          # AppTest UI টেস্ট (টাইপ + Generate)
  test_v2_features.py     # v2 টেস্ট (প্রজেক্ট, কাস্টম ভয়েস, ওয়েভফর্ম, আবেগ, সেটিংস)
  measure_rss.py          # সর্বোচ্চ RAM পরিমাপ (v2 পথসহ)
```

## টেস্ট

```bash

.venv-test/bin/python tests/test_app_ui.py
```

যাচাই করে; v2 টেস্টে প্রজেক্টের সংরক্ষণ/ডাউনলোড/আপলোড, নমুনা যাচাই,
ওয়েভফর্ম PNG, মাস্টার প্রম্পটের ৩টি উদাহরণ বাক্যের আবেগ, এবং
